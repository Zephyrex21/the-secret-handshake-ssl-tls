# The Secret Handshake — SSL/TLS

Interactive 10-slide Computer Networks (Unit V, Security) presentation on how SSL/TLS secures a connection. Plain HTML, CSS and JavaScript; no build step.

**Run:** open `index.html`, or `python -m http.server 8000` and visit `http://localhost:8000`.

**Controls:** arrows / Space / PageUp / PageDown to move, `F` fullscreen, dots on the right to jump.

**Slides:** problem and needs · TLS in the stack · crypto toolkit · Diffie–Hellman · certificates and trust chain · TLS 1.3 handshake · TLS 1.2 vs 1.3 · attacks and defences · summary. See `docs/PRESENTATION_PLAN.md` for timing.

**Note:** an educational presentation. Diffie–Hellman uses toy numbers; the handshake and certificate demos are animations, not a live TLS session.
